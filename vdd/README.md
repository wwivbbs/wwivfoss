# vdd (planned)

Win32 Virtual Device Driver for the `vdd` transport, used on 32-bit Windows
NTVDM and NTVDMx64. Built with MSVC as x86 and x64 DLLs.

To be written from the public documentation only: the Windows DDK VDD
interfaces (`vddsvc.h`, `isvbop.h`) and the FOSSIL specification. See
`docs/design.md`.
